# Wireframes do Bicho no Bolso

O PDF pronto está em `docs/wireframes-bicho-no-bolso.pdf` (A4 deitado).

Para mudar uma tela, edite `telas.py` (cada tela: id, nome, status, se precisa
de servidor, elementos e nota) e gere de novo, nesta pasta:

    python3 gera.py          # cria wf.html
    # depois abra wf.html no Chrome e imprima em PDF (A4 paisagem, sem margens)

Status: E = já existe no site · P = parcial · N = novo.
